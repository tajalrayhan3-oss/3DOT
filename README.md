# 3DOT

Construction management SaaS for UAE businesses.

## Planned modules
- Authentication and company onboarding
- Clients and projects
- Employees and timesheets
- Quotations and invoices
- Company logo and letterhead
- English and Arabic (RTL)
- 7-day trial and monthly AED subscription
- Web and Android apps

This repository is the source of truth for the 3DOT application.
